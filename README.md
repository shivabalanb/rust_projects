# Rust Projects

My journey learning Rust by following along with [The Rust Programming Language Book](https://rust-book.cs.brown.edu/) - all 21 chapters completed! 🦀

### What's Here

This repo contains all the projects and exercises I worked through while learning Rust. It was my introduction to the language and I had a lot of fun building these. I followed along with every chapter, completed all the quizzes, and built the example projects. The book was an excellent introduction to Rust's unique features like ownership, borrowing, and the type system.

### Featured Projects

These are the main projects I built out:

- **`hello/`** - A simple HTTP web server with thread pooling
- **`corporate_db/`** - Interactive command-line database management system
- **`guessing_game/`** - Classic number guessing game with random number generation
- **`minigrep/`** - Text search tool similar to Unix grep

## My Reflection

This was my first real exposure to Rust, and I have to say it’s a fascinating language. Coming from JavaScript, Python, and other high-level languages, this book opened my eyes to many new concepts. It explored abstractions that are usually hidden away in those languages and even revisited material I once dreaded in my computer architecture and OS classes, this time in a way I actually enjoyed.
Some of my personal favorite topics were ownership, borrowing, closures, and threads. Some concepts I am iffy on are macros and little advanced nuances in traits and types. Overall, I loved the journey and I’m excited to start building cool projects with Rust!
